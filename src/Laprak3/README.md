# Laprak 03 - Program Pengelolaan Data Nilai Siswa

## 📌 Deskripsi
Program Java sederhana untuk mengelola data nilai siswa dalam suatu kelas. Program ini memanfaatkan konsep Pemrograman Berorientasi Objek (Class & Object), struktur kontrol perulangan (`for loop`), kondisional (`if-else`), serta input/output interaktif menggunakan `Scanner`.

## 🚀 Fitur Utama
* Input data siswa secara dinamis (Nama dan Nilai).
* Penentuan status kelulusan otomatis (Batas lulus: Nilai >= 70).
* Perhitungan rata-rata nilai kelas.
* Rekapitulasi jumlah siswa yang lulus dan tidak lulus.

## 📁 Berkas Kode
* `Student.java` : Kelas cetak biru (*blueprint*) objek siswa.
* `main.java` : Berkas utama alur input, looping, dan perhitungan.
